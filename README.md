# QuickNotes (fork)

A fork of [sabbasn/quicknotes](https://github.com/sabbasn/quicknotes), a simple notepad addon for World of Warcraft.

## Why this fork exists

The original deletes a note when you left-click it. This fork adds a setting to choose which mouse button deletes a note:

- **Left-click to delete** (default, same as the original)
- **Right-click to delete**

Toggle it in the addon's settings under **Behavior** > **Right-click to delete notes**. The choice is saved per character.

Otherwise, this fork is currently the same as the original. It keeps the same addon name and saved variables, so existing notes and settings carry over.

## Installation

Download this repo and place it in your `Interface/AddOns/` folder as `QuickNotes`.
